# Texas Hold'em Desktop Game Source Code

[简体中文](README.md) | [繁體中文](README.zh-TW.md) | [GitHub Pages](https://deepseek7878.github.io/texas-holdem-desktop/)

Texas Hold'em Desktop is a cross-platform desktop poker game source-code project for Windows, macOS and Linux. It is designed for offline practice, AI opponents, tournaments, club rooms, private games, hand history, statistics tracking, themes and commercial desktop-client extensions.

The project covers a complete desktop Texas Hold'em experience, including offline gameplay, multi-table logic, AI opponents, tournament mode, statistics, hand replay, theme customization, cross-platform packaging and operation-version extensions.

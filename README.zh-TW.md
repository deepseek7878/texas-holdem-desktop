# Texas Hold'em Desktop — 德州撲克桌面遊戲原始碼

[English](README.en.md) | [繁體中文](README.zh-TW.md) | [GitHub Pages](https://deepseek7878.github.io/texas-holdem-desktop/)

Texas Hold'em Desktop 是一个跨平台德州撲克桌面遊戲原始碼專案，適合用於 Windows、macOS、Linux 桌面客户端、單機练习、AI 對手、錦標賽、俱樂部、朋友局、資料統計、手牌歷史和主題皮肤系統开发。

專案覆盖德州撲克完整桌面端体验，包括離線娱乐、多人桌逻辑、AI 對手、赛事模式、勝率統計、手牌回放、主題自訂、跨平台打包和營運版本扩展。

> 合规說明：请在合法地区、合法业务范围内使用。本專案適合作为桌面遊戲开发、规则引擎、教学演示、離線练习和商业系統技术参考。

## 核心功能

| 模块 | 功能 |
|---|---|
| 桌面客户端 | Windows、macOS、Linux 跨平台运行 |
| 游戏模式 | 单人练习、快速对战、挑战赛、錦標賽、朋友局 |
| AI 對手 | 離線 AI 玩家、难度等级、策略模拟 |
| 牌局流程 | Pre-flop、Flop、Turn、River、Showdown |
| 資料統計 | VPIP、PFR、3-bet、勝率、位置勝率、下注热图 |
| 手牌歷史 | 牌局记录、回放、导出 CSV/JSON |
| 赛事系統 | 盲注升级、报名、淘汰、排名、积分榜 |
| 主題系統 | 夜间模式、经典模式、赌场风格、自訂配色 |
| 多语言 | 简体中文、繁体中文、英文、韩文、马来文等可扩展 |
| 打包發布 | Electron Builder、PyInstaller、Unity/C++ 客户端可扩展 |

## 推荐專案结构

```text
client/                 # 桌面客户端原始碼
engine/                 # 德州撲克规则与牌局引擎
ai/                     # AI 對手与策略模块
tournament/             # 錦標賽逻辑
stats/                  # 資料統計和手牌歷史
assets/                 # UI、音效、主題、图片资源
database/               # SQLite/JSON 資料结构
config.example/         # 脱敏配置示例
scripts/                # 构建、打包、部署脚本
docs/                   # GitHub Pages 产品与技术文档
tests/                  # 自动化测试
.github/workflows/      # CI 与 GitHub Pages 工作流
```
